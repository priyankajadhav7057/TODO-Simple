# ToDo App

A simple and responsive ToDo application built using HTML, CSS, and JavaScript. This project allows users to add and delete tasks, helping them manage daily activities efficiently.

## Features

* Add new tasks
* Delete completed or unwanted tasks
* Simple and user-friendly interface
* Responsive design
* Built using pure JavaScript without external libraries

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```
ToDo-App/
│
├── index.html      # Main HTML file
├── style.css       # Styling for the application
├── app.js          # JavaScript functionality
└── README.md       # Project documentation
```

## How It Works

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. The task is added to the task list.
4. Click the **Delete** button to remove a task.
